# Василевс — агент презентаций для Claude Code / Codex

Бриф → таблица слайдов на утверждение → продающий текст к каждому слайду (копирайтер) →
пилотная картинка → все слайды через Genosai (ChatGPT Image 2.5, 1K) → проверка глазами →
таблица на приёмку → лёгкий PPTX (текст в заметках) + «презентация текстом» .md/.docx.

Каждый слайд — одна картинка: заголовок, 2–3 предложения и сцена, которая **без текста
сама пересказывает смысл слайда**. Ни один шаг не делается без вашего «да».

**Установка:** [УСТАНОВКА.md](УСТАНОВКА.md) (Windows и Mac, Claude Code и Codex).

Зов: **«Василевс, сделай презентацию про …»**.

## Что внутри

| Файл | Что это |
|---|---|
| `SKILL.md` | Инструкция агента: гейты, шаги, команды |
| `бриф.md` | Вопросы брифа и карточка на подтверждение |
| `промпты.md` | Правила промптов для картинок слайдов |
| `копирайтер.md` | Правила продающего текста к слайдам |
| `project.example.json` | Шаблон проекта презентации |
| `scripts/gen.py` | Генерация картинок через Genosai API (параллельно, ретраи, защита от лимитов) |
| `scripts/review_table.py` | Markdown-таблица картинок для приёмки |
| `scripts/build_pptx.py` | Сжатие картинок + сборка PPTX (продающий текст → заметки) |
| `scripts/build_script.py` | «Презентация текстом» — .md и .docx |
| `agents/vasilevs.md` | Определение субагента для Claude Code (`~/.claude/agents/`) — по желанию |

Проекты создаются в `projects/<название>/` внутри папки скилла (в репозиторий не попадают).

## Требования

Python 3.10+ с `pillow`, `python-pptx`, `python-docx`; аккаунт Genosai с ключом `sdk_live_…`
в `~/.secrets/genosai-slides.env`. Подробности — в УСТАНОВКА.md.
