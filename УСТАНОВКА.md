# Как установить Василевса — пошагово, с нуля

Василевс — это «агент»: набор инструкций и трёх маленьких программ, которые понимает
Claude Code (или Codex). Ставите один раз, потом просто пишете в чат:
**«Василевс, сделай презентацию про …»** — и он ведёт вас за руку: бриф → тексты слайдов →
продающий текст → пилотная картинка → все слайды → проверка → PPTX + документ.

Установка занимает 10 минут. Ничего программировать не нужно.

---

## Шаг 0. Что должно быть на компьютере

| Что | Зачем | Как проверить | Где взять |
|---|---|---|---|
| **Claude Code** (или **Codex**) | ИИ-помощник, в котором живёт Василевс | Открывается окно/терминал с Claude Code | claude.ai/code → приложение для Windows/Mac, или `npm install -g @anthropic-ai/claude-code` |
| **Python 3** (3.10+) | На нём работают скрипты: генерация картинок, сборка PPTX и Word | `python --version` (Mac: `python3 --version`) | python.org/downloads; **на Windows при установке поставьте галочку «Add Python to PATH»** |
| **Node.js** (18+) | Только для установки одной командой (способ А) | `node -v` | nodejs.org → кнопка LTS |
| **Аккаунт Genosai** с кредитами | Здесь рисуются картинки слайдов (модель ChatGPT Image 2.5, ~6 кредитов за слайд) | — | genosai.io → регистрация |

> Как открыть терминал: Windows — нажмите Win, наберите `PowerShell`, Enter.
> Mac — Cmd+Space, наберите `Terminal`, Enter. Все команды ниже вставляются туда и
> запускаются клавишей Enter. Проще всего — запускать команды прямо из Claude Code:
> напишите ему «выполни команду …», и он сделает это сам.

## Шаг 1. Установить Василевса

Один способ на выбор.

**Способ А — одной командой (рекомендуем).** В терминале:

```bash
npx skills add upsalesvideo/vasilevs-agent
```

Установщик спросит, куда ставить — выберите Claude Code (или Codex) и «глобально»
(для всех проектов). Готово: Василевс лежит в `~/.claude/skills/vasilevs`
(Codex: `~/.codex/skills/vasilevs`).

**Способ Б — вручную, без командной строки.**

1. Откройте https://github.com/upsalesvideo/vasilevs-agent
2. Зелёная кнопка **Code → Download ZIP**. Распакуйте архив.
3. Переименуйте распакованную папку в `vasilevs` и положите её:
   - Claude Code: в `C:\Users\<ваше имя>\.claude\skills\` (Windows) или `~/.claude/skills/` (Mac).
   - Codex: в `~/.codex/skills/` (если папки нет — создайте).
   Папки `.claude` / `.codex` скрытые: в проводнике включите «Показывать скрытые файлы»
   или вставьте путь в адресную строку вручную.

**Только для Claude Code — подключить как субагента (по желанию, но удобно).**
Скопируйте файл `agents/vasilevs.md` из папки скилла в `~/.claude/agents/` (Windows:
`C:\Users\<ваше имя>\.claude\agents\`). Тогда Василевс работает в отдельном окне-агенте
и не засоряет основной чат. Можно попросить Claude Code: «скопируй
~/.claude/skills/vasilevs/agents/vasilevs.md в ~/.claude/agents/».

## Шаг 2. Python-пакеты для скриптов

Один раз в терминале:

```bash
pip install pillow python-pptx python-docx
```

(Mac, если `pip` не найден: `pip3 install pillow python-pptx python-docx`.)

## Шаг 3. Ключ Genosai

1. Зайдите на genosai.io → профиль → **API-ключи** → создать ключ. Он начинается с `sdk_live_`.
2. Создайте файл `~/.secrets/genosai-slides.env` (Windows: `C:\Users\<ваше имя>\.secrets\genosai-slides.env`)
   с одной строкой:
   ```
   GENOSAI_API_KEY=sdk_live_ваш_ключ
   ```
   Проще всего попросить Claude Code: «создай файл ~/.secrets/genosai-slides.env со строкой
   GENOSAI_API_KEY=sdk_live_…» — он всё сделает сам.
3. Проверка (из папки скилла):
   ```bash
   python scripts/gen.py x --balance
   ```
   Должно показать баланс кредитов. Ошибка 401 — ключ скопирован с ошибкой; 403 — ключ
   не `sdk_live_` (тестовые ключи не подходят).

## Шаг 4. Проверить, что всё работает

В чате Claude Code напишите: `Василевс, ты здесь?` — он представится и начнёт бриф.
Первую презентацию сделайте короткой, на 5–6 слайдов, чтобы понять ритм: бриф → таблица
слайдов → «да» → продающий текст → «да» → одна картинка → «да» → все слайды → «да» → файлы.

## Что получится на выходе

- `…/projects/<название>/out/<название>.pptx` — презентация, каждый слайд — картинка;
  продающий текст в заметках докладчика; размер 2–5 МБ, можно слать в мессенджер.
- `…/projects/<название>/out/<название>_текст.docx` и `.md` — вся презентация текстом.
- `slide_01.png … slide_NN.png` — картинки по отдельности.

## Частые вопросы

- **Картинка с ошибкой в тексте / лишний палец.** Василевс сам это ловит и перегенерирует.
  Если что-то проскочило — напишите «переделай слайд 4», он перерисует только его.
- **Хочу другой стиль.** На этапе пилота скажите, что не так, — стиль поправят до генерации
  остальных слайдов. Лучший результат — когда вы прислали картинку-образец в брифе.
- **Сколько стоит.** Один слайд ≈ 6 кредитов Genosai (1K). Дека на 12 слайдов с пилотом и
  парой перегенераций — около 100 кредитов.
- **Mac: «python не найден».** Используйте `python3` — Василевс знает про это.
