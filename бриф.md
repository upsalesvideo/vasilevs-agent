# Бриф перед презентацией

Задавай по 3–4 вопроса за раз, не анкетой. Если пользователь уже что-то сказал в запросе —
не переспрашивай, а зафиксируй в карточке. Ссылки и файлы, которые прислали, открой сам.

## Блок 1. Зачем и кому
1. **О чём презентация и какова цель?** Что зритель должен сделать/понять/почувствовать
   после последнего слайда (купить, согласовать бюджет, записаться, запомнить три тезиса)?
2. **Кто аудитория?** Роль, уровень знаний по теме, что для них важно, чего опасаются.
   Один человек или зал? Знакомы с автором или холодные?
3. **Где и как будут смотреть?** Живое выступление (мало текста, спикер говорит) /
   отправка в мессенджер, читают сами (текста больше, слайд самодостаточен) /
   и то и другое.

## Блок 2. Содержание
4. **Исходный материал:** текст, тезисы, план, ссылка, документ? Или писать с нуля по теме?
5. **Сколько слайдов?** Если не знают — предложи ориентир: выступление 10–12,
   отправка для чтения 8–15, короткая продажа 6–8.
6. **Обязательные элементы:** что точно должно быть (цифры, кейсы, цены, контакты,
   призыв к действию на последнем слайде, титульный слайд с именем/компанией).
7. **Язык текста на слайдах** (по умолчанию русский).

## Блок 3. Стиль (обязательно)
8. **Есть ли образец стиля картинкой?** Фото/скриншот слайда, который нравится, страница
   сайта, обложка, любая картинка «хочу так». Попроси прислать файл или путь. Сохрани в
   `projects/<slug>/refs/`. Можно несколько.
9. Если образца нет — **предложи 2–3 направления словами** под аудиторию, например:
   - деловой фотореализм (люди в офисе, мягкий свет, спокойная палитра);
   - чистая плоская иллюстрация (крупные формы, 2–3 фирменных цвета, много воздуха);
   - тёмный «технологичный» (глубокий фон, неон-акценты, 3D-объекты);
   - тёплый лайфстайл (естественный свет, живые люди, пастель).
   И спроси про **фирменные цвета/логотип** — есть ли, применять ли.
10. **Анти-примеры:** чего точно не надо (стоковые улыбки, роботы, синий градиент…).
11. **Формат кадра:** 16:9 по умолчанию; 4:3 для старых проекторов; 9:16 / 1:1 — если это
    для сторис/ленты.

## Карточка брифа (заполни и покажи на подтверждение)

```
Тема / цель:        …
Аудитория:          …
Контекст показа:    выступление / для чтения / оба
Слайдов:            N (+титульный, +финальный CTA)
Материал:           есть (файл/ссылка) / пишем с нуля
Обязательно:        …
Язык:               русский
Стиль:              образец: <файл> / направление: …
Цвета / лого:       …
Не надо:            …
Формат:             16:9, chatgpt-image-2-5, 1K
Кредиты (оценка):   N × 6 ≈ … + пилот и перегенерации
```

После «да» на карточку — переходи к слайдам (Шаг 1 в SKILL.md).
