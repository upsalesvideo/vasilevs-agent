# Быстрый старт: как поставить Василевса, если вы не технарь

Василевс — помощник, который делает презентации внутри Claude Code (или Codex): задаёт вам
вопросы, пишет тексты слайдов, рисует картинки и отдаёт готовый PowerPoint. Ставить его
будете не вы, а сам ИИ — вам нужно только скопировать и вставить два сообщения.

## Что нужно заранее

1. **Claude Code** (или Codex) установлен и открыт. Если ещё нет — claude.ai/code, там
   кнопка «скачать» для Windows и Mac.
2. **Аккаунт на genosai.io** и в нём **API-ключ** — это строка, которая начинается
   с `sdk_live_`. Где взять: genosai.io → войти → профиль → «API-ключи» → «Создать».
   Скопируйте её куда-нибудь, она понадобится во втором сообщении.

Больше ничего знать не нужно: Python, папки, команды — всё сделает ИИ.

## Шаг 1. Откройте Claude Code и вставьте этот промпт целиком

Скопируйте весь блок ниже (от первой до последней строки), вставьте в чат Claude Code
и нажмите Enter. Если Claude по ходу спросит разрешения что-то установить или создать
файл — отвечайте «да» / «разрешить».

```
Установи мне агента «Василевс» для создания презентаций из репозитория
https://github.com/upsalesvideo/vasilevs-agent — сделай всё сам, ничего не спрашивай
кроме разрешений.

Сделай по порядку:
1. Проверь, что есть Python 3.10+ (на Mac — python3). Если нет — скажи, как поставить
   с python.org, и остановись.
2. Скачай репозиторий (git clone или ZIP по ссылке) и положи его содержимое в папку
   ~/.claude/skills/vasilevs (на Windows это C:\Users\<моё имя>\.claude\skills\vasilevs).
   Если пользуешься Codex — в ~/.codex/skills/vasilevs.
   Если удобнее, можешь выполнить: npx skills add upsalesvideo/vasilevs-agent
3. Скопируй файл agents/vasilevs.md из этой папки в ~/.claude/agents/vasilevs.md
   (только для Claude Code; для Codex пропусти).
4. Установи Python-пакеты: pip install pillow python-pptx python-docx
   (на Mac — pip3, если pip не найден).
5. Проверь, что файлы на месте: SKILL.md, бриф.md, копирайтер.md, промпты.md,
   scripts/gen.py, scripts/build_pptx.py, scripts/build_script.py, scripts/review_table.py.
6. Напиши мне одной строкой: «Василевс установлен, теперь пришлите ключ Genosai» —
   и жди ключ.
```

## Шаг 2. Когда Claude ответит «установлен» — вставьте второе сообщение

Замените `sdk_live_XXXX` на ваш настоящий ключ из genosai.io:

```
Вот мой ключ Genosai: sdk_live_XXXX
Создай файл ~/.secrets/genosai-slides.env (на Windows — C:\Users\<моё имя>\.secrets\genosai-slides.env)
с одной строкой: GENOSAI_API_KEY=<мой ключ>
Затем проверь ключ командой: python ~/.claude/skills/vasilevs/scripts/gen.py x --balance
(на Mac — python3). Если увидишь баланс кредитов — напиши «Ключ работает, баланс N».
Если ошибка 401 — скажи, что ключ скопирован неверно; если 403 — что нужен ключ
вида sdk_live_, а не тестовый.
```

## Шаг 3. Проверка

Напишите в чат:

```
Василевс, ты здесь?
```

Он представится и начнёт бриф — задаст вопросы про тему, аудиторию и стиль. Дальше
просто отвечайте. На каждом шаге он будет ждать вашего «да»: тексты слайдов → продающий
текст → одна пробная картинка → все слайды → готовые файлы.

Первую презентацию сделайте маленькой, на 5–6 слайдов, чтобы почувствовать ритм.

## Если что-то пошло не так

Вставьте в чат Claude Code:

```
Василевс не работает. Прочитай ~/.claude/skills/vasilevs/УСТАНОВКА.md, проверь по нему
все шаги (папка скилла, файл агента, пакеты Python, файл с ключом Genosai), найди,
чего не хватает, исправь и покажи, что именно было не так.
```

Подробная инструкция с объяснениями — в файле УСТАНОВКА.md рядом.
